# Logos das instituições

Arquivos PNG locais usados para identificar exclusivamente as 12 instituições de
`src/constants/institutions.ts`, que também define as opções do seletor de contas.
Instituições personalizadas usam o ícone escolhido para a conta.

Origem: [logos-bancos-br](https://github.com/rzmt/logos-bancos-br).
`sources.json` registra a instituição, o ISPB e a fonte original de cada imagem.
O código e os metadados do catálogo têm licença MIT (`LICENSE.txt`). As logos
são marcas de seus respectivos titulares, usadas para identificação das
instituições, conforme o [aviso do catálogo](https://github.com/rzmt/logos-bancos-br/blob/main/DISCLAIMER.md).
