# Logos das bandeiras

Logos de Visa, Mastercard, Elo, American Express e Hipercard, obtidas do catálogo
[Datatrans Payment Logos](https://github.com/datatrans/payment-logos/tree/master/assets/cards).
Os SVGs originais foram preservados e rasterizados em PNG 240 × 160 para uso
offline pelo componente Image no Android, iOS e web. Não há dependência de
runtime para a conversão.

Fonte de cada arquivo: `https://raw.githubusercontent.com/datatrans/payment-logos/master/assets/cards/<nome>.svg`.
SVGs e PNGs são distribuídos sob [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/),
com atribuição a Datatrans; a única transformação foi a conversão de formato.
A licença completa do catálogo está em `LICENSE.txt`. Marcas pertencem aos respectivos
titulares e são utilizadas para identificação da bandeira selecionada.
